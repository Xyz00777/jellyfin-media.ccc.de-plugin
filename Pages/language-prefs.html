Media.CCC.de Language Preferences

Jellyfin 12 renders plugin pages without running their scripts, so this page cannot read or save your preferences. The plugin serves the page itself, which works on every Jellyfin version.

Open Language Preferences

First time? You will be asked for your own Jellyfin API key once, so the page knows which account to save the preferences for. Create a key under Dashboard > Advanced > API Keys. The key is checked against the server and then discarded.
