MediaCCC.de

Configure synchronization of conference talks from media.ccc.de

Storage

Directory where watchlist data is stored. Default: /config/plugins/ccc-media/watchlists/

Quality

Quality preference for downloaded recordings. Falls back to available quality if preferred not found.

Synchronization

How often to check for new conference content. Default: 6 hours. Range: 1-168 hours.

Language Preferences

Comma-separated ISO 639-1 language codes. Talks will use the first available match. Default: Original language.
Common: en (English), de (German), fr (French), es (Spanish)
Comma-separated ISO 639-1 language codes. Falls back to first available subtitle language if no match.
