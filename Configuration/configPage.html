Media.CCC.de Configuration

Jellyfin 12 renders plugin pages without running their scripts, so this form cannot read or save your configuration. The plugin serves an equivalent page itself, which works on every Jellyfin version.

Open Media.CCC.de Settings

First time? The unlock token is printed in the Jellyfin server log when the plugin starts. Open /media_ccc/settings and paste that token into the unlock form. It unlocks the page for 30 days.
